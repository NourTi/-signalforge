# Security Policy

Do not report security issues through public GitHub issues.

For responsible disclosure, email [rafaraf201@gmail.com](mailto:rafaraf201@gmail.com) with the subject line `SignalForge security report`. Do not include user data, credentials, or exploit code in a public report.

This repository contains a static marketing site only. The secure SignalForge application, its database, credential encryption, email delivery, and discovery features are not deployed in this repository.
