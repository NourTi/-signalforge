# Contributing to SignalForge Public Site

This repository is the static public landing site for SignalForge. Keep changes focused on the public brand, positioning, accessibility, and GitHub Pages compatibility.

Do not add application secrets, customer data, SMTP credentials, private product URLs, or backend code to this repository. The secure SignalForge application is deliberately hosted separately.

Before proposing a change, open `index.html` locally in a browser and check desktop and mobile layout, keyboard navigation, readable contrast, and the private-beta contact link.
