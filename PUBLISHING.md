# Publishing Notes

The public SignalForge landing site is published through GitHub Pages at `https://nourti.github.io/-signalforge/` from the repository `main` branch and root folder.

This repository intentionally contains only static public marketing assets. It does not contain the SignalForge server, database, encrypted SMTP credentials, public-business discovery service, user authentication, or any customer data. Those secure application capabilities remain separate from the GitHub Pages deployment.

To publish, enable GitHub Pages from the `main` branch and the repository root in the GitHub repository settings. For a branded URL later, add a custom domain through GitHub Pages settings and configure the matching DNS records with the domain provider.
